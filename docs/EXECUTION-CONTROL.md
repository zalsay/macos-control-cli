# v0.1.7 执行控制条、三秒倒计时与鼠标接管

## 交互约定

控制条常驻屏幕，不会三秒后自动消失。首次输入前先显示「AI将在 3 秒后接管，请松开鼠标」，按 3 → 2 → 1 自动开始，无需点击执行。倒计时期间不发送输入，可移动鼠标，按钮为禁用的“继续”和可用的“取消”；运行时“暂停”可用，暂停后“继续”可用。只有首次接管和用户点击继续时需要倒计时，其他串行动作不重复等待。

- 运行后用户移动鼠标、拖动、滚动、点击控制条之外的位置，或切换到其他应用时，原生输入暂停，避免双方争用桌面输入；倒计时内这些活动不触发暂停。
- AI 自己生成的鼠标事件和控制条区域的事件不会触发接管。
- 暂停会同步释放本 helper 持有的鼠标按键/键盘按键，不释放用户自己的按键。已进入的同步副作用完成后暂停才返回，后续副作用不能继续。
- 取消倒计时或用户暂停后不会自动恢复。用户点击“继续”后重新倒计时三秒；新的输入调用等待剩余倒计时，不能重放上一个点击、部分输入文本或暂停前/暂停期间排队的动作。Agent 应先观察上一步结果，再构造新操作。
- 窗口授权、连接、已保留截图帧和已成功工具回执继续有效。暂停后的观察无需点击“继续”。
- 控制条不抢键盘焦点，只监听鼠标类事件，不请求键盘 Input Monitoring，也不保存用户鼠标轨迹或页面内容。
- AI 的目标坐标覆盖控制条时，控制条先移动到同屏幕另一侧，再继续原有指针归属校验；控制条不会被自动关闭，AI 也不能借网页点击去触发控制按钮。
- disconnect、窗口失效清理、daemon stop 或 Copis 集成中的原有紧急停止结束该控制。控制条与监听器随生命周期清理。

“继续”发起本组件下一次三秒接管倒计时。它不会自行重启一个已结束的 Agent 对话，也不为其他 Agent 重放中断的工具；Agent 的后续调用应遵循其运行状态及用户继续指令。

## 状态与并发

取消代次与输入代次独立。观察只使用取消代次；每次原生输入持有绑定当前 lease 和 input epoch 的 `ChromeInputPermit`。暂停与从 paused 恢复的两个边界均推进输入代次；暂停前及暂停期间排队的请求都不会在恢复后复活。

stdin 接收请求时先保存当时的输入代次，再排入串行队列。这样即使请求尚未开始、用户已经暂停后又执行，旧请求仍不能取得新的 permit。该代次是 helper 内部字段，JSON 请求不允许自行指定。

CGEventPost、keyDown 以及激活/AX setter/AXPress 的每次提交，都与暂停共用同一把提交锁。主线程切换先完成，再进入锁；取消结束回调在锁外调用，UI 使用 lease 校验拒绝旧控制的迟到回调。激活通知先保存 activated PID 与单调时钟送达时间，再异步到主线程处理；明确的外部激活不会被随后切回 Chrome 吞掉，身份缺失时回读真实前台。与鼠标事件一样，倒计时内的已知旧事件不会在接管后造成误暂停。

原生 Helper 使用 `NSApplication.run()` 完成 AppKit 启动并派发交互事件。旧的普通 RunLoop 仅适合展示型提示，无法承担按钮事件处理；真实 CLI 回归先因外部 AX 窗口为空失败，切换事件循环后通过。

## 工具与版本兼容

内部原生暂停错误为 `USER_PAUSED`；独立 CLI 公开响应使用：

```json
{
  "protocolVersion": 1,
  "ok": false,
  "error": {
    "code": "FOCUS_LOST",
    "reason": "USER_PAUSED",
    "message": "桌面输入已暂停，请点击屏幕上方控制条的继续按钮并等待 3 秒倒计时；暂停不会自动恢复，也不会重放旧输入"
  }
}
```

旧主程序继续按可恢复的失焦处理，不销毁原生 runtime 和控制条。新主程序只在 `FOCUS_LOST + USER_PAUSED` 的固定组合或直接的 `USER_PAUSED` 中识别 `CHROME_USER_PAUSED`。未知 reason 不改变错误分类，原生 message/stderr 不直接转发到模型。

取消未确认时返回 `CANCEL_UNCONFIRMED`，保留连接所有权和可读状态，但拒绝后续输入；只能重试 disconnect 或停止私有 daemon，收到取消 ACK 后才清除连接。

显式用户暂停与普通失焦区分：Start/Observe 保留 paused 状态与当前授权，不能自动解除；后续新输入仍由原生门禁判断，只有用户点击继续、倒计时结束后新输入成功，主进程才清除暂停状态。模型不能通过重新 Start、切换 control 或 shell/AX/CG 操作控制条来解除用户暂停。无需增加新的 Agent 工具。
