# v0.2.2 Chrome顶部毛玻璃提示条

## 用户约束

只覆盖操作Chrome的标签栏与地址栏，不进入网页内容区；保留现有毛玻璃效果，并显示当前执行的操作。

## 实现边界

- 复用原NSPanel和NSVisualEffectView，保留hudWindow、behindWindow、暗色vibrant外观、原生三联按钮和非激活行为。
- 对Google Chrome目标，从精确窗口的原生AXToolbar读取几何；跳过网页、scroll area、sheet等子树，不读取网页DOM或URL/输入内容来猜区域。
- 连接时只读复核所选窗口并预读原生顶部区域（已有AX权限时，不触发授权或激活）；文件选择的模态循环可能不响应AXWindows，只在专用选择动作期间、窗口ID/PID/bundle及几何均未变时复用已验证区域。普通动作不用此复用路径，原生sheet/焦点验证不变。
- 从窗口顶端到导航工具栏底边确定允许区域，限制为窗口内且最高160pt；72pt紧凑面板始终放在可见顶部区域内，水平居中，不再按整屏居中。
- AX窗口定位与属性遍历使用剩余0.6秒预算，读前设置有限超时、读后核对截止点；根窗口暂不可见时仅预算内只读重试，不激活或猜窗口。
- 顶部区域不可验证、过窄或过矮时拒绝输入，不回退为覆盖网页。窄窗口上的遮挡优先横向移动并按可用空间缩窄，最低320pt并为原生窗口边缘留20pt余量；自家提示条刚移动时，按0.2秒重试预算等待原SLS/AX/SLS完整命中检查同步（同步系统查询耗时另计），持续遮挡仍拒绝；仍无位置时保留原指针guard拒绝，不在网页里避让。
- 可见期间每250ms发起有界的原生区域核对，在后台串行查询且仅允许一个在途任务，不阻塞主线程的暂停/关闭。位置或工具栏范围变化后再更新，不改鼠标/截图坐标。目标失效或无安全区域时暂停并隐藏，不能继续后台输入。
- 显示“将执行/正在/已完成/未完成”及操作类型：点击、双击、滚动、输入文字、白名单按键、选择文件、观察。不会显示输入正文、剪贴板内容或本地文件路径。
- 标题与观察只更新已有提示；关闭后停止定位timer，不由迟到操作结果或Observe复活。倒计时、用户暂停、许可代次与精确焦点/几何/指针校验均保留。
- desktop-control选Chrome时同样使用此布局，其他普通应用保留原位置与尺寸策略。

## 验证

纯布局BDD检查顶部边界、窗口移动、横向避让、不可用区域拒绝和敏感文案不泄露。

`tests/toolbar-toast-smoke.sh`仅创建本进程AppKit对象，不截图/投递桌面输入；检查毛玻璃属性、72pt紧凑布局、原生三联按钮不压住文字、当前/完成状态、窗口跟随、避让后不被timer重置、关闭后不复活及无焦点切换。

还需运行原有原生协议、取消、执行门禁与Chrome坐标/文件选择回归，防止位置和状态改动影响输入链路。真实视觉效果须由用户在实际应用窗口确认，结构测试不代替视觉验收。

## 2026-10-22 结果

- 92项Rust回归通过；新增连接时目标复核与原生提示区域预读测试。既有文件选择spy按新增的只读窗口复核步骤更新，路径错误仍在原生选择前拒绝。
- 153项原生JSONL smoke及布局、操作文案、缓存边界、指针同步等待、执行门禁/取消等BDD通过。
- 新AppKit对象回归覆盖72pt毛玻璃、原生按钮不遮文字、操作/完成状态、移动跟随、横向避让、在途查询时关闭、重复show不排队、迟到回调不复活及布局失败保持暂停。旧对象回归在并行编译时一次触及12秒wrapper超时，单独复跑通过；未为此修改生产超时。
- 隔离Chrome真实回归：两个1000×800窗口位置、6次网页单击落点相对独立AX中心误差均为0；连续移动与双击语义通过。两次鼠标点击地址栏均在顶部横向避让后取得真实AX焦点，Escape退出，未导航或输入URL。
- 文件选择真实回归：普通前台及Chrome明确在后台、独立冷helper首次AX查询两种情况，均在原生对话框关闭后由测试页面确认收到预期文件；未上传。
- 真实测试只操作私有profile、loopback页面、测试文件与私有runtime，finally关闭本次daemon与测试Chrome。

## 实测问题与处理

1. 模态文件对话框期间AXWindows可返回-25204，即使CG窗口可见。保留强身份检查，不依赖标题/猜测偏移；改为连接时预读顶部区域，并仅在专用文件选择期间复用匹配身份和几何的只读元数据。
2. 重复show会重置“查询在途”标志、让旧provider排队。新增阻塞provider回归先失败，再修复为旧查询完成前不接受新任务；revision仍丢弃迟到结果。
3. 真实地址栏点击时，提示条移开后WindowServer短暂仍命中自身面板。保留拒绝而非豁免；增加横向安全余量，并仅在本提示条确实移动后有界重做原完整指针校验。每轮查询前后重新检查许可、焦点与几何；查询期间取消/暂停/失焦优先返回，持续外部遮挡不会被放行。

以上不是视觉验收；毛玻璃外观、实际位置和文字可读性仍需用户在真实Chrome窗口确认。未承诺所有Chrome布局、其他Space或任意应用工具栏都可识别。
