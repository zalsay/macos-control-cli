- [ ] Add proposed internal `FixtureWriterBinding` server-owned concrete type and channel `installFixtureWriter(_ binding:)`/`sendBound(_ admission:)` entry points as in spec, adjusting visibility minimally and compile-checking exact signatures. Route ready, diagnostics and scheduled responses through binding, preserving phase tokens and request/handler behavior; diagnostic delivery is never authorization.
- [ ] Under original channel lock reject binding if any pending legacy bytes exist; sticky bound marker and weak binding never downgrade on nil. Server strongly retains binding; head and queued jobs retain binding/context/frame, without a channel-context cycle. Add synchronous owner-drop revoke as needed; original stop/release handles eventual cleanup.
- [ ] Before touching one-shot state or foreign revocation, check receiving-channel structural ownership of the admission/binding/lease. Ordinary close may have no typed cause. Implement EOF local-closed/revoked check, preserving failure status 1 even if EOF arrives before writer catch, while clean peer EOF stays 0.
