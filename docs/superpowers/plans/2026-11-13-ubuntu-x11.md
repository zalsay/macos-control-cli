# Ubuntu 22.04 当前 Xorg 桌面支持

已获用户授权的方案：复用 Linux X11 后端，直接连接当前 GNOME X11 会话，不启动 Xvfb/Openbox/noVNC。不触碰当前 Docker 桌面或主仓库未提交内容。

1. 在既有 execution 平台判定中区分 Docker 与显式启用的 Linux 宿主模式；宿主拒绝 Wayland、root 和远程 DISPLAY。
2. 复用 Gate 和控制条，为宿主恢复人工键鼠/失焦暂停、三秒倒计时；硬停止与未知状态不得由软事件覆盖。Docker 规则不变。
3. 将模式接入 helper、Service 权限回执及 Host 能力声明；宿主维持独占 owner，不启用 Docker 的闲置接续。
4. 适配当前 EWMH/GNOME X11 窗口/文件选择框，并强制普通 Firefox 使用 X11。保留精确帧、窗口身份及原像素校验。
5. 为既有 build.sh/install.sh 增加 Linux 分派和用户级安装路径，启动包装器继承当前 DISPLAY/XAUTHORITY/session bus；不提权、不新建显示器、不自动操作用户桌面。
6. 仅验证变更范围：模式、权限与暂停门禁定向单元测试；单进程构建 Linux 二进制；在隔离 X11 fixture 上直接 MCC 检查输入/暂停。GNOME 实机、Wayland、跨机器部署不据此宣称验收。

主 agent 实施和自审，不派发代码审查，不运行全量回归。不自动提交、合并、推送或部署至现有容器。
