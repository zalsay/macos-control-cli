# MCC / MBC macOS 配置面板

在仓库新增 `desktop/`，作为单独构建的 Tauri 桌面 App。一个窗口，三个页面：Host、蓝牙、脚本。Rust 后端调用现有 MCC 和 MBC，使用明确的路径与参数数组；前端只调用定型接口，不开放通用 shell。现有 CLI、安装路径与固件继续可单独使用。第一版默认查找现有 MCC 安装，也支持手动选取完整构建包目录；不会自动安装或替换二进制。

## Host

可设置监听地址、端口（默认 `127.0.0.1:8765`）、TLS 证书和私钥、token 文件。提供生成 token 和选择已有 token 文件两种方式。生成时复用 `mcc host token init`，使用私有目录；界面默认只展示文件路径及配置状态，token 不进入参数、应用配置或日志。可复用 `mcc host tls init` 在新目录初始化本机证书，已有证书不覆盖。

保存配置与应用配置分开。用户点击启动后，App 用 `mcc host start` 启动其管理的进程，展示启动成功或端口、证书、权限等失败原因。只停止 App 能确认由自己启动的 Host，沿用 Host 的正常停止机制；不接管既有 Host、daemon 或控制会话。监听地址、端口或 token 变更在下次启动时生效，保存不重启。App 退出时对自己的 Host 发起正常关闭。

## 蓝牙

复用 `mbc/MBCMain.swift` 的 CoreBluetooth 和 NUS 客户端，补充只读设备发现和结构化连接测试。发现结果标注设备名和此 Mac 上的 peripheral UUID；选中后先验证 NUS 命令服务和 `status` 回应，再保存。配置由同一用户下的新版 MBC 读取，独立 `mbc`、`mcc --eb` 和 Host 的逐步 `eb: true` 共用同一个设备选择。未配置时保留现有 `pilot-2` 行为；明确选择后只连接选定 UUID，找不到时直接报错。Status 测试打开并关闭 NUS 会话，不发送鼠标键盘输入。HID 系统配对仍在 macOS 蓝牙设置完成；本机配置不修改其他 Mac。

## 脚本

导入已有 JSON 到 App 的脚本库，可搜索、查看、编辑、复制、导出与删除库内副本。原文件保持不变。保存或导入前复用 `src/script.rs` 的文件大小和步骤校验；需要初始 `frameId` 的脚本可保存为需提供帧的脚本。编辑器高亮标出 `eb: true` 步骤与失败步骤编号。

第一版只管理脚本，不在界面启动键鼠操作。可复制已有 `mcc script` 调用模板以便在 CLI 执行。现有 JSON 格式、连接与帧约束、逐步 ESP 路由不变。

## 验收与交付

只验证本次改动：构建 Tauri App，检查三页操作；用临时数据验证 token 权限、Host 启停归属和监听地址、脚本导入与校验；用模拟设备结果验证选择逻辑、旧默认值及指定设备失联时的行为。真实蓝牙验收单独记录系统 HID 配对与 NUS `status` 结果。源码和构建产物独立于已安装版本，不进行全量回归、自动安装、GitHub 推送或发布。主 agent 审查。
